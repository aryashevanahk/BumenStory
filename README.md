# BUMENSTORY

Portal informasi Kabupaten Kebumen — sejarah, kuliner, budaya, dan profil daerah.

🌐 **Live:** [bumenstory.vercel.app](https://bumenstory.vercel.app)

---

## Fitur

- Hero slideshow (auto ganti 10 detik)
- Timeline interaktif di halaman sejarah
- Accordion tips di halaman kuliner
- Video embed YouTube
- Form kontak
- Responsive (desktop & HP)
- SEO friendly (meta, sitemap, robots.txt)

## Struktur
bumenstory/
├── index.html # Beranda
├── sejarah/ # Sejarah + timeline
├── kuliner/ # Kuliner + accordion
├── budaya/ # Budaya + kerajinan
├── tentang/ # Tentang + form kontak
├── assets/img/ # Gambar
├── css/style.css # Stylesheet
├── js/script.js # Interaktivitas
├── robots.txt
├── sitemap.xml
└── vercel.json

## Tech Stack

HTML5 · CSS3 · Vanilla JavaScript · Feather Icons · Vercel

Tanpa framework, tanpa CMS.
