# BUMENSTORY

Portal informasi Kabupaten Kebumen yang menyajikan informasi mengenai **sejarah, kuliner, budaya, dan profil daerah**.

🌐 **Live:** [bumenstory.vercel.app](https://bumenstory.vercel.app)

---

## Fitur

* **Hero Slideshow** — gambar hero berganti otomatis setiap 10 detik
* **Timeline Interaktif** — menampilkan perjalanan sejarah Kebumen secara interaktif
* **Accordion Tips** — informasi dan tips kuliner yang dapat dibuka dan ditutup
* **Video YouTube** — integrasi video melalui YouTube Embed
* **Form Kontak** — halaman untuk menyampaikan pesan atau informasi
* **Responsive Design** — menyesuaikan tampilan pada desktop dan perangkat mobile
* **SEO Friendly** — dilengkapi metadata, `sitemap.xml`, dan `robots.txt`

---

## Struktur Project

```text

│
├── css/

│

```

---

## Tech Stack

* **HTML5** — struktur halaman
* **CSS3** — styling, layout, dan responsive design
* **Vanilla JavaScript** — interaktivitas website
* **Feather Icons** — ikon antarmuka
* **Vercel** — deployment dan hosting

> BUMENSTORY dibuat tanpa framework frontend dan tanpa CMS. Seluruh struktur, tampilan, dan interaktivitas dibangun menggunakan teknologi web dasar.
